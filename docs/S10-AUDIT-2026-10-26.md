## Changes in this audit

- `.gitattributes`: automatic text detection instead of forcing every unknown
  file to text; explicit binary handling for extensionless Exynos9820 services,
  firmware and image/archive formats. Removed obsolete device-specific rules.
- `create_work_dir.sh`: set the system device identity from TARGET_CODENAME,
  rather than copying the donor ODM device identity.
- `build_legacy_flashable_zip.sh`: check all five destination block devices and
  exact reviewed capacities before the first image write. Reject mounted
  destinations, missing devices, unreadable sizes and invalid size output.
  Keep PIT/boot opt-ins and the reviewed boot SHA-256 requirement. No EFS,
  modem, recovery, DTBO, userdata formatting or repartitioning is introduced.
  Add explicit NOT SAFE TO FLASH text, final ZIP integrity check, SHA-256
  sidecar, DEFLATE level 5 and progress completion after the boot write.
- Common camera/product-feature/legacy modules: remove dead Exynos990 branches
  and references to the removed Exynos990 tree; preserve the S10 branch behavior.
- Tests: execute the generated recovery checker against six simulated cases
  without block writes; exercise the real packager for all four targets.
  Verify S10 ELF checkout bytes against Git objects and ELF segment bounds.
- CI: remove the separate source-review workflow as requested; source review
  and regression checks are performed locally. Preserve
  bounded thermal XML, donor asset metadata and relevant decoded parser files
  in the compilation diagnostic artifact after failures.
